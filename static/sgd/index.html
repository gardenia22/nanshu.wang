The bias of
the optimizer
why SGD refuses to memorize

An overparameterized network has infinitely many ways to fit its training data — including a pure lookup table. Gradient descent almost never finds that one. This manual builds the reason from the ground up: the loss defines where the solutions are; the optimizer decides which one you get.

CH 01 — THE PUZZLEUNDERDETERMINATION

Zero training loss is not one model. It's an infinite family.

Take 7 data points and a degree-14 polynomial: 15 coefficients, 7 constraints. The system is underdetermined, so an 8-dimensional space of coefficient vectors fits the data exactly. Every member of that family has identical training loss: zero. Training loss alone cannot tell them apart.

Yet they behave completely differently between the points. Below, the slider moves you through this family. Every curve you see passes through all 7 points perfectly — the training loss never changes. Only the null-space component changes: the part of the parameters the data cannot see.

The question this raises If the data can't distinguish these models, something else must. In deep learning that "something else" is not an explicit regularizer you wrote down — it's the optimizer. Chapters 2–6 identify exactly what it prefers.
CH 02 — THE FIRST THEOREMMINIMUM NORM

Gradient descent lands at the smallest solution it can reach.

Here is the entire mechanism, visible in two dimensions. One equation, w₁ + 2w₂ = 4, two unknowns: the solution set is a line. Run gradient descent on the squared error and a basic fact of linear algebra takes over — the gradient always points along the data direction a = (1, 2). GD can only ever move parallel to a. The component of your initialization perpendicular to the data is frozen forever.

Consequence: from the origin, GD converges to the point on the solution line closest to zero — the minimum-ℓ₂-norm interpolator. No regularizer was written down; the geometry of the update rule is the regularizer. Drag the start point and watch which solution you get.

solution norm ‖w‖ — min possible —
Blue line: all zero-loss solutions. Red path: GD trajectory (drag anywhere to set a start). Dashed circle: the smallest norm any solution can have — from the origin, GD lands exactly on the tangent point. From elsewhere, it lands at your start's projection: initialization is part of the prior.

For linear regression this is a theorem. For deep networks the same phenomenon appears in disguise: with appropriate parameterizations, gradient descent implicitly minimizes norms, ranks, or margins that were never in the loss (Gunasekar et al., 2017). Small-norm functions are smooth, simple functions — GD's first vote against memorization.

CH 03 — SPECTRAL BIASLIVE TRAINING RUN

Networks learn low frequencies first. Watch one do it, live.

This is not a recording. The panel below contains a real MLP — 1 → 64 → 64 → 1, tanh activations, Adam — implemented in this page, training in your browser right now when you press start. The target is a sum of a slow wave and a fast wave: y = sin(2πx) + 0.3·sin(10πx).

Watch the order of events. The network fits the slow component almost immediately, then spends thousands of steps grinding out the fast ripple. This is spectral bias (Rahaman et al., 2019): the function a network represents changes fastest in its low-frequency directions. "Simple structure first, fine detail later" — memorizing noise is the highest-frequency thing you can do, so it is what SGD does last and least.

Why this kills the lookup table A lookup table is spectrally flat — it needs all frequencies at once, everywhere. SGD builds functions coarse-to-fine, so at any finite training time the network is the smoothest function so far consistent with the data. Early stopping isn't a hack; it's harvesting the optimizer's prior mid-descent.
CH 04 — AFTER ZERO LOSSMARGIN MAXIMIZATION

Training accuracy hits 100% — and GD keeps working.

Logistic loss on separable data never actually reaches zero; it only decays as the weights grow. So after the classifier is already perfect on the training set, gradient descent keeps moving — and it moves in a very particular direction. Soudry et al. (2018) proved that the weight direction converges to the maximum-margin separator: the exact SVM solution, with no margin term anywhere in the loss.

Below, twenty points, two classes, plain gradient descent on logistic loss. The dashed line is the max-margin boundary (computed ahead of time by running the same dynamics to convergence). Watch the red boundary reach 100% accuracy early, then slowly rotate onto the dashed line.

CH 05 — DOUBLE DESCENTLIVE LEAST-SQUARES

Past the interpolation threshold, more parameters help.

Classical statistics says test error is U-shaped in model size: too few parameters underfit, too many overfit. Modern practice says the U is only the first half of the curve. This panel computes the rest, live: random-feature regression (ReLU(wₓ·x + b) features, min-norm least squares) on 20 noisy samples, with the feature count P swept from 1 to 45.

At P = n = 20 — exactly enough parameters to interpolate — the fit is forced through every noise wiggle with no freedom left, and test error explodes. Push past it and something classical intuition forbids happens: among the now-many interpolating solutions, min-norm least squares (Chapter 2's hero) picks ever-smoother ones. Test error comes back down. Overparameterization plus the optimizer's small-norm bias is the regularizer (Belkin et al., 2019; Nakkiran et al., 2019).

CH 06 — GROKKINGMEMORIZE → GENERALIZE

Sometimes the network memorizes first — then switches.

Train a small transformer on modular arithmetic with only part of the table shown, and something strange happens (Power et al., 2022). Training accuracy hits 100% quickly: pure memorization, test accuracy at chance. Then, thousands of steps later — with training loss already near zero — test accuracy suddenly jumps to 100%. The network abandons its lookup table for the general algorithm.

Why? The memorizing circuit and the generalizing circuit both fit the training data — Chapter 1's family again — but the general one has smaller weight norm. Weight decay and SGD's drift keep grinding norm down after the loss is flat, and eventually the cheap solution wins. Scrub the timeline:

Schematic after Power et al. (2022). Blue: train accuracy. Red: test accuracy. Gold: weight norm. The gap between the two accuracy jumps is the memorization plateau — zero loss, no understanding. The norm's slow decline is the optimizer's preference doing its work invisibly, until the phase change.
Synthesis — back to compression Six views of one fact: gradient descent minimizes loss subject to an unwritten preference for small, smooth, low-frequency, wide-margin solutions. Small-description-length solutions. Even given infinite parameters — enough capacity to memorize everything — the optimizer's dynamics still route through compression, because compressed solutions are the ones its geometry can cheaply reach and prefers to keep. Memorization isn't forbidden; it's just expensive in the currency SGD spends.
